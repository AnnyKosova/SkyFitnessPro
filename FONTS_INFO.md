# Информация о шрифтах проекта

## Основной шрифт: Roboto

**Подключение:**
- Используется `next/font/google` для оптимизированной загрузки
- Подключен в `src/app/layout.tsx`
- Доступны все веса: 100, 300, 400, 500, 700, 900
- Поддерживаются normal и italic стили
- Поддержка латиницы и кириллицы

**Использование в CSS:**
```css
font-family: var(--font-roboto), fallback-fonts;
```

## Кастомный шрифт: StratosSkyeng

**Проблема:**
- Дизайнер использовал кастомный шрифт StratosSkyeng
- Этот шрифт недоступен публично (вероятно, корпоративный шрифт Skyeng)

**Решения:**

### Вариант 1: Использовать похожий шрифт
Можно использовать похожий шрифт как fallback:
- **Inter** - современный геометрический шрифт
- **Montserrat** - похож по стилю
- **Poppins** - геометрический sans-serif

### Вариант 2: Использовать Roboto с другим весом
Для выделения текста можно использовать Roboto с другим весом (bold, black)

### Вариант 3: Если есть файл шрифта
Если дизайнер предоставит файл шрифта (.woff2, .ttf), можно:
1. Поместить файлы в `public/fonts/`
2. Подключить через `@font-face` в CSS

**Пример подключения кастомного шрифта:**
```css
@font-face {
  font-family: 'StratosSkyeng';
  src: url('/fonts/StratosSkyeng-Regular.woff2') format('woff2'),
       url('/fonts/StratosSkyeng-Regular.woff') format('woff');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
```

## Рекомендации

1. **Основной текст:** Использовать Roboto (400, 500)
2. **Заголовки:** Roboto (700, 900) или похожий шрифт
3. **Акценты:** Если нужен особый стиль - использовать Roboto с другим весом или стилем
