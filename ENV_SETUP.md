# Настройка переменных окружения

## Создание .env.local

Создайте файл `.env.local` в корне проекта со следующим содержимым:

```env
# API Base URL
# Для локальной разработки используйте /api/fitness
# Для продакшн замените на реальный URL API
NEXT_PUBLIC_API_URL=/api/fitness
```

## Важно

- Файл `.env.local` уже добавлен в `.gitignore` и не будет попадать в репозиторий
- Для продакшн настройте переменные окружения в Cloudflare Pages
- Переменные с префиксом `NEXT_PUBLIC_` доступны в браузере
