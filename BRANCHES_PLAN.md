# План работы с ветками Git

## Стратегия работы

- **main** - главная ветка, только для мерджа проверенных веток
- **hw1, hw2, hw3...** - ветки для разработки отдельных этапов
- Каждая ветка проходит проверку перед мерджем в main

## Workflow работы с ветками

### Создание новой ветки:
```bash
git checkout main
git pull origin main
git checkout -b hw1
```

### Работа в ветке:
```bash
# Делаем изменения
git add .
git commit -m "Описание изменений"
git push origin hw1
```

### Мердж в main (после проверки):
```bash
git checkout main
git pull origin main
git merge hw1
git push origin main
```

### Удаление ветки после мерджа:
```bash
git branch -d hw1
git push origin --delete hw1
```
