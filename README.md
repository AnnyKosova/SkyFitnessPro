# SkyFitness Pro

Онлайн-платформа для занятий фитнесом дома. Приложение предоставляет доступ к различным курсам тренировок: йога, стретчинг, фитнес, степ-аэробика и бодифлекс.

## 🚀 Технологии

- **Framework**: Next.js 14+ (App Router) / React 18+
- **Язык**: TypeScript
- **Стилизация**: CSS Modules
- **HTTP клиент**: Axios
- **State Management**: React Context API
- **Тестирование**: Jest + React Testing Library
- **Линтинг**: ESLint + Prettier
- **Деплой**: Cloudflare Pages

## 📋 Функциональность

### Для всех пользователей
- Просмотр всех доступных курсов
- Просмотр детальной информации о курсе
- Авторизация и регистрация

### Для авторизованных пользователей
- Добавление курсов в свой профиль
- Просмотр своих курсов с прогрессом
- Удаление курсов
- Просмотр тренировок курса
- Отслеживание прогресса по упражнениям
- Заполнение прогресса тренировок

## 📁 Структура проекта

```
/src
  /components      - переиспользуемые компоненты
  /pages           - страницы (или app для Next.js)
  /api             - API клиент и функции
  /types           - TypeScript типы
  /hooks           - кастомные хуки
  /utils           - утилиты
  /styles          - глобальные стили
  /context         - React Context
/public            - статические файлы
```

## 🛠 Установка и запуск

### Требования
- Node.js 18+
- npm или yarn

### Установка зависимостей
```bash
npm install
# или
yarn install
```

### Настройка переменных окружения
Создайте файл `.env.local` в корне проекта:
```
NEXT_PUBLIC_API_URL=/api/fitness
```

### Запуск в режиме разработки
```bash
npm run dev
# или
yarn dev
```

Приложение будет доступно по адресу: http://localhost:3000

### Сборка для продакшн
```bash
npm run build
# или
yarn build
```

### Запуск продакшн версии
```bash
npm start
# или
yarn start
```

### Линтинг
```bash
npm run lint
# или
yarn lint
```

### Форматирование кода
```bash
npm run format
# или
yarn format
```

### Тестирование
```bash
npm test
# или
yarn test
```

## 📄 Страницы приложения

1. **Главная страница** (`/`) - список всех курсов
2. **Страница курса** (`/course/:id`) - детальная информация о курсе
3. **Страница профиля** (`/profile`) - профиль пользователя и его курсы
4. **Страница тренировки** (`/course/:id/workout/:workoutId`) - просмотр тренировки и прогресс

## 🔐 Авторизация

Приложение использует JWT токены для аутентификации. Токен сохраняется в LocalStorage и автоматически обновляется при истечении.

## 📱 Адаптивность

Приложение полностью адаптировано для:
- Мобильных устройств (320px+)
- Планшетов (768px+)
- Десктопов (1024px+)

## 🚢 Деплой

Приложение задеплоено на Cloudflare Pages. 

### Переменные окружения

Создайте файл `.env.local`:
```
NEXT_PUBLIC_API_URL=your_api_url
# или для React
REACT_APP_API_URL=your_api_url
```
