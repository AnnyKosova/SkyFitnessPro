# Папка для изображений

Эта папка предназначена для статических изображений проекта.

## Структура папок (рекомендуется):

```
/images
  /logo          - логотипы
  /courses       - изображения курсов (йога, фитнес и т.д.)
  /icons         - иконки
  /avatars       - аватары пользователей (если нужны)
  /backgrounds   - фоновые изображения (если нужны)
```

## Использование в Next.js:

В Next.js изображения из папки `public` доступны по пути от корня:

```tsx
// Пример использования
<Image 
  src="/images/logo/logo.svg" 
  alt="SkyFitness Pro Logo"
  width={200}
  height={50}
/>
```

## Форматы изображений:

- **Логотипы:** SVG (предпочтительно) или PNG
- **Фото курсов:** JPG, WebP (для оптимизации)
- **Иконки:** SVG или PNG

## Оптимизация:

Next.js автоматически оптимизирует изображения при использовании компонента `<Image />` из `next/image`.

## Загружаемые файлы:

- Логотип SkyFitness Pro
- Изображения курсов (Йога, Стретчинг, Фитнес, Степ-аэробика, Бодифлекс)
- Другие необходимые изображения
