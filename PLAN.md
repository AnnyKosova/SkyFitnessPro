# План разработки SkyFitness Pro

## Обзор проекта
Веб-приложение для онлайн-тренировок с авторизацией, управлением курсами и отслеживанием прогресса.

## Технологический стек
- **Framework**: Next.js 14+ (App Router) или React 18+ с React Router
- **Язык**: TypeScript
- **Стилизация**: CSS Modules (или Tailwind CSS опционально)
- **Роутинг**: Next.js встроенный или react-router-dom
- **HTTP клиент**: Axios
- **State Management**: React Context API (или Redux Toolkit при необходимости)
- **Тестирование**: Jest + React Testing Library
- **Линтинг**: ESLint + Prettier
- **Деплой**: Cloudflare Pages

## Вопросы для обсуждения

1. **Next.js vs React**: Рекомендую Next.js для лучшего SEO и производительности, но если нужен более простой роутинг - React Router
2. **State Management**: React Context достаточно для этого проекта, Redux может быть избыточен
3. **Стилизация**: CSS Modules или Tailwind? CSS Modules проще для pixel perfect
4. **API документация**: Когда будет доступна документация API?
